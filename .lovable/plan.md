# خطة التنفيذ — 4 مهام

## 1) فحص بصري وتأكيد للخصومات في PDF و Excel
أضف لكل خصم (دين/التزام/أصل معفى/خيار غير مستحق) سطراً يوضح:
- **القيمة المُدخلة** الأصلية
- **السبب**: مُحتسب (دين حالّ مليء) / مستبعد (دين غير مليء، أصل وقفي محبّس، خيار Unvested، أصول ثابتة للاستعمال)
- **المرجع الشرعي** المختصر

**ملفات تتغير:**
- `src/components/zakat/PrintReport.tsx` — توسيع `PrintReportData.rows` بحقول اختيارية: `deductions?: Array<{ label, amount, included: boolean, reason: string, ref?: string }>`
- `src/components/zakat/ReactPdfReport.tsx` — جدول «بيان الخصومات والمبرّرات» بعد جدول البنود
- `src/lib/exportExcel.ts` — ورقة جديدة «بيان الخصومات» تستهلك نفس البنية

## 2) تحويل عملات تلقائي قبل التصدير
- مكوّن `CurrencyConverterCard` صغير يسمح بإدخال أسعار صرف يدوية لكل عملة فرعية مستخدمة (USD, EUR, GBP, AED ...) مقابل عملة التقرير
- خدمة `src/lib/fx.ts` نقية: `convert(amount, from, to, rates)` + `applyFxToReport(data, rates)`
- استدعاء `applyFxToReport` قبل `downloadReportExcel` و `downloadReportPdf`
- إضافة عمود «أصل العملة / السعر المستخدم» في PDF/Excel للشفافية

> ملاحظة: لا أعتمد على سعر صرف حي تلقائي عبر API لأن ذلك يدخلنا في نفقات شبكية ومخاطر سرية؛ المستخدم يُدخل السعر أو يستورده من `prices.functions.ts` الموجود.

## 3) بادج QR على صفحة PDF النهائية
- إضافة حقل `reportId` (يُولَّد من تجزئة قصيرة لمحتوى التقرير + الطابع الزمني)
- توليد QR (نص = `https://<origin>/verify?rid=<reportId>` أو ملخص JSON موقّع بالـ HMAC إذا توفر السر)
- استخدام `qrcode` (مكتبة موجودة في كثير من المشاريع؛ سأتأكد وأضيفها إذا لزم) لإنتاج `dataURL` ثم وضعها داخل `Image` في `@react-pdf/renderer`
- يظهر QR في رأس/تذييل الصفحة الأخيرة بجوار اعتماد المراجع

## 4) ضبط زكاة الركاز كزكاة الزروع والثمار (عرض دائم)
حالياً السطر في `CompanyTab` صحيح. أضمن نفس السلوك في `IndividualTab` بحيث:
- يظهر دائماً بصرف النظر عن القطاع
- بنفس شكل البطاقة المختصرة في الصورة (عنوان + نسبة + جملة توضيحية) قبل القسم التفصيلي القابل للطي

## نطاق غير مشمول
- لا أغيّر سياسة المصادقة أو RLS
- لا أضيف API خارجي لأسعار الصرف (يدوي + قابل للتعبئة لاحقاً من `metalPrices.functions.ts`)
- لا أعدّل ملفات Supabase التوليدية
